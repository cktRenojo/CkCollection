# **App Name**: C&K Apparel

## Core Features:

- Product Catalog: Display products in distinct categories: Women, Men, New Arrivals, and Best Sellers.
- Product Details: Show detailed product information (name, images, sizes, pricing, description).
- Product Filters: Implement basic filtering for products based on category, price, and size.
- Shopping Cart (Mock): Simulate a shopping cart for adding items, though checkout will be non-functional.
- Contact Page: A 'Contact Us' page with company information.
- AI Product Suggestions: Use an AI tool to recommend similar items based on the current viewed product.
- Admin Interface: Simple page or form with authentication to add or remove items.

## Style Guidelines:

- Primary color: Muted Indigo (#5C6BC0) for a sense of calm and reliability. This color is not too distracting but still provides a modern, clean feel, avoiding overly vibrant tones which could clash with product imagery.
- Background color: Very light desaturated lavender (#F0F4C3) to create a soft, neutral backdrop that keeps focus on the products. This light shade works well in a light color scheme, enhancing readability and visual appeal.
- Accent color: Soft Violet (#9575CD) to highlight interactive elements such as buttons, filter options, and calls to action. As a contrasting color, the violet is approximately 30 degrees to the left of the indigo hue in the color wheel, but is distinct in both brightness and saturation.
- Body font: 'PT Sans' (sans-serif) for the body text to maintain readability and a modern appearance.
- Headline font: 'Playfair' (serif) for headlines to create a sleek and high-end feel.  Use 'PT Sans' for the body text when paired.
- Use minimalistic vector icons for categories, filters, and navigation. Ensure icons are consistent and easily recognizable.
- Implement a grid-based layout to showcase products neatly. Use white space effectively to avoid a cluttered appearance.
